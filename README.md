# Portfolio

A modern, responsive portfolio website showcasing my projects, skills, and experience.

## Overview

This portfolio is a personal website built to demonstrate my web development expertise and highlight my professional work. It features a clean, modern design with an intuitive user interface.

## Technology Stack

- **HTML** (51%) - Semantic markup and page structure
- **CSS** (43.1%) - Styling and responsive design
- **JavaScript** (5.9%) - Interactive features and dynamic functionality

## Features

- 🎨 **Responsive Design** - Looks great on desktop, tablet, and mobile devices
- ⚡ **Fast & Lightweight** - Optimized for quick loading times
- 🎯 **User-Friendly** - Clean navigation and intuitive layout
- 💼 **Project Showcase** - Display of my best work and achievements
- 📱 **Mobile-Optimized** - Fully functional on all screen sizes

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/omarelnabawi/portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

3. Open `index.html` in your browser to view the portfolio

## Project Structure

## Usage

Simply open the portfolio in a web browser. Navigate through the sections to explore:
- About me
- My projects and work samples
- Skills and expertise
- Contact information

## Customization

To personalize this portfolio:

1. **Edit HTML** - Update content in `index.html`
2. **Modify CSS** - Customize styling in `css/styles.css`
3. **Add JavaScript** - Enhance interactivity in `js/script.js`
